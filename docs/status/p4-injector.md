# Status: the injector (Part 2, step 4, PLAN "Zero integration" delivery 2)

Branch `p4/injector`. Decisions D-130 (proxy, cookie, Coolify routing) and D-131 (page bundle).

## What is built

| Part | Where | What it does |
|---|---|---|
| Proxy | `apps/injector/*.go` (Go 1.26, `golang.org/x/net/html`) | Reverse proxy for chosen hosts (`INJECTOR_UPSTREAM`, or `INJECTOR_UPSTREAMS` by host). For a page load with a valid reviewer cookie it asks the app for `Accept-Encoding: identity` and no conditional headers, streams the HTML through the tokenizer writing raw bytes, and adds one script tag after `<head>` (or before the first token of an implied head) with the nonce of the enforced CSP. Passes through everything else: other types, gzip or brotli bodies, attachments, 204/206/304, fetches, iframes, prefetches, `X-Review-Skip`. Gives up after 256 KB without a head or on a 64 KB token; recovers panics with the response unchanged. Strips the reviewer cookie from every request to the app. WebSockets and server-sent events stream. |
| `/__toolbar/` | `apps/injector/proxy.go` | `toolbar.js` (immutable with `?v=<hash>`), `login` (to the server), `session` (POST hand-off, sets the cookie), `logout`, `status`, `health`, and `api/v1/...`, a relay to the server limited to the upload routes, the `X-Toolbar-Page: 1` header and the same origin, which adds the reviewer's device token as a bearer. |
| Reviewer cookie | `apps/injector/cookie.go`, `apps/server/src/lib/server/review/` | `tbr1.<payload>.<HMAC-SHA256>`, shared format pinned by `apps/injector/testdata/review-cookie.json` (both the Go and the TypeScript tests read it). |
| Server | `apps/server/src/routes/review/start/` | `/review/start?origin=&next=`: sign in if needed, confirm "Open <host> with the toolbar", mint a device token "Review on <host>" (Settings, Connected browsers; `INJECTOR_COOKIE_DAYS`), post the signed value to `<origin>/__toolbar/session`. Only origins in `INJECTOR_ORIGINS`, or while that is empty, origins of projects (D-123) in the person's workspaces; off (404) without an `INJECTOR_SECRET` of 32+ characters. New capture source `injector` ("Toolbar on the site"). |
| Page bundle | `apps/extension/page/` (`pnpm --filter @toolbar/extension build:page`, part of `build`) | One classic script, 63 KB gzipped, from `@toolbar/capture` (MAIN hooks and isolated recorder in the page realm, usual bridge) with `PageSession` as the Transport. Bar at the bottom centre: Comment (pick an element, write; without a trace a `replay` capture of the last 60 s with the annotation on the element's locator, during a trace it joins the trace), Start trace and Stop trace with elapsed time (a `trace` capture streamed every 2 s, across page loads of the tab, so the server's spans route works on it), menu (hide, turn review off). The page's project sets the masking preset, body policy and workspace, and events wait until it is known (`awaitConfig`); no project means staging and the active workspace. Open shadow root, constructed stylesheet, positions through the CSSOM. |
| Image | `apps/injector/Dockerfile` | Node stage builds the bundle, Go stage a static binary, runtime `scratch` (binary plus bundle, non-root, `HEALTHCHECK /injector healthcheck`). |
| Coolify | `deploy/injector/traefik-open-toolbar-injector.yml`, `deploy/injector/docker-compose.injector.yml` | File router for `/data/coolify/proxy/dynamic/`, priority 10000, matching only the chosen hosts' `/__toolbar/` and requests carrying the reviewer cookie (`HeaderRegexp` on `Cookie`), so visitors never pass through the injector. The compose resource joins the `coolify` network and has no domain of its own. |
| Docs | `apps/injector/README.md`, `docs/configuration.md` (Injector), `docs/dev.md`, `docs/architecture.md` 11a, `.env.example`, `docker-compose.yml` | |

## How it was verified

- Go unit tests (`cd apps/injector && go test -race ./...`, also `pnpm --filter @toolbar/injector test`): 14 document shapes (head with attributes and upper case, implied head, text first, BOM, `<head>` inside a comment and inside a script string, self-closing head, truncated at EOF, end tag first, later heads untouched), each at one byte per read, every two-chunk split point, three-chunk splits and with data-plus-EOF reads; a 2 MB document; scan limit; a token over 64 KB; read errors before and after the head. CSP nonce selection (script-src-elem over script-src over default-src, several policies and headers, report-only ignored, first directive wins), unsafe nonces dropped. Proxy tests with httptest: no cookie means byte-identical output and untouched `Accept-Encoding` and conditionals; a reviewer gets the tag with the nonce and nothing else changed, `identity` upstream, no conditionals, no reviewer cookie at the app; gzip from the app passes through byte for byte; JSON, XHTML and attachments pass; no injection for `X-Review-Skip`, fetches, iframes, prefetches, expired, foreign-origin, https-on-http, tampered and garbage cookies; `X-Forwarded-Proto: https` with `__Host-tb_review`; an upstream that dies before the head; streaming (the tag arrives before the app finishes); session (cookie flags, open redirect, foreign token, GET refused); login redirect; the API relay (bearer added, cookies, origin and page header removed, Set-Cookie dropped) and its refusals (no page header, cross origin, no cookie, route off the list, wrong method, dot segments); assets and path traversal; upstreams by host.
- Server: `apps/server/test/review-cookie.test.ts` signs the shared vector byte for byte as Go does and checks the refusals; `apps/server/test/projects.int.test.ts` checks that project origins count only while `INJECTOR_ORIGINS` is empty and only for members, and that an issued cookie verifies and holds a working device token. Extension: `apps/extension/test/page-session.test.ts` (page routes equal the route table, the 60 s ring keeps a replayable rrweb segment, a comment uploads as the server expects, a trace streams numbered chunks, finalizes with its comments and is picked up again by the next page).
- Compose test (`apps/injector/test/run.sh`, 5 Playwright tests, headless Chromium with no extension, about 30 s): the injector image in front of the lab (:5173) on :3506, uploads to this worktree's dev server on :3306 (database `toolbar_p4_injector`, prefix `p4-injector/`, mock OIDC). (1) Without the cookie the lab is untouched and has no toolbar. (2) `/__toolbar/login`, mock OIDC sign-in, confirm, hand-off: the lab loads with the toolbar from `/__toolbar/`, `document.cookie` does not show the reviewer cookie. (3) Submit order (hidden 500), Show profile (throws) and a warning, then Comment on an element: the server has a `replay` capture of source `injector` titled from the comment, with `POST /api/fail 500`, the TypeError, the warning and rrweb chunks, and none of the bundle's own uploads in its network log. (4) Start trace, Save, navigate to `/form`, a console error, a comment, Stop trace with a note: a `trace` capture with requests and console rows from both pages, the navigation to `/form`, a `changed` span from the server's spans route. (5) `X-Review-Skip` gives no toolbar; the lab's streamed `/slow-raw` page gets the tag before its last chunk; the lab's WebSocket works through the proxy; "Turn off review on this site" removes the toolbar. (6) An nginx page behind the same injector with `script-src 'nonce-...' 'strict-dynamic'; style-src 'self'`: the tag carries the app's nonce, the toolbar runs and is styled, the app's nonce script still runs and its inline script stays blocked, no other CSP report.
- The Traefik file parsed and loaded in Traefik v3.5 (router, rule and service created; the only errors were the missing `letsencrypt` resolver and the absent container name of a bare test run).
- `pnpm -r --workspace-concurrency=2 build`, `check` and `test` pass. As on `p4/trace`, `apps/server`'s `auth.int.test.ts` fails one test only while the worktree's `.env` (with `ALLOWED_EMAIL_DOMAINS=test`) is present; without it all 191 pass.

## What is not built or not verified

- Not run on Coolify or Nuru: the Traefik file was parsed, not routed through, and the injector was not tested behind TLS (the `__Host-` path is covered by unit tests only).
- The flows and parity suites were not rerun on this branch. The extension's code is unchanged apart from its build script (which now also builds the page bundle into `.output/page`) and a type union; the server gained a route, a source value (the dashboard's source filter lists one more option) and a dev-server `allowedHosts` entry.
- The project path (no `INJECTOR_ORIGINS`, a project origin instead) is covered by `apps/server/test/projects.int.test.ts`, not by the compose test, which uses `INJECTOR_ORIGINS`. The production preset in the page bundle was not exercised end to end.
- The page bundle does not reuse the reviewer UI of `p4/reviewer-ui` (not merged when this branch was made): text highlights, drawings, element screenshots and voice notes are extension-only. Its Comment is element plus text.
- Page comments carry the element's `TargetRef` as the annotation target, not a locator packet (D-128, merged from `p4/locator` at the end of this work): the packet is built by the extension's worker and isolated script, and the page bundle does not build it yet. Mapped error stacks (D-129) are also the worker's; page captures have raw stacks.
- No screenshots or keyframes from the page bundle (a page cannot capture its own pixels without a prompt); the DOM replay covers them. Iframes are not captured.
- The bundle shares the page realm: app scripts could call the upload relay as the reviewer while the page is open (limited to the upload routes). Page console calls show `toolbar.js` as their source in the browser's devtools.
- A trace can lose up to two seconds before a navigation when the last chunk exceeds the 64 KB keepalive budget.
- `pnpm -r build` and `test` now need Go 1.26 for `@toolbar/injector`.
- Decision numbers D-130 and D-131 follow main's last row (D-129) at the time of the final merge; `p4/reviewer-ui` numbered its rows from D-117, so its merge will need to renumber.
