# Auth area status

Branch `area/auth`. One line per task row from `docs/tasks.md` (area auth, plus the foundations X-05 and X-06). Checks ran against the area server on :3101 (`toolbar_auth` database, Mailpit on :8025) and the test build of the extension on Xvfb `:111`.

How to rerun:

- Units and DB integration: `pnpm --filter @toolbar/server test` (`test/auth.unit.test.ts`, `test/auth.int.test.ts`) and `pnpm --filter @toolbar/extension test` (`test/auth-client.test.ts`).
- E2E: `pnpm --filter @toolbar/extension build:test` with `WXT_SERVER_URL` set, then `npx playwright test tests/auth` in `e2e/` with `SERVER_URL` and `E2E_DISPLAY` from `.env`. `tests/auth/providers.spec.ts` also needs `E2E_PROVIDERS=1`, a mock OIDC provider and provider env vars on the server (the file header lists them).
